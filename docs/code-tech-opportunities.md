Refreshed: placeholder — regenerated each cycle by bot/earning/code_techs.py

This file documents the format the code-techs module writes. The module itself
is the source of truth; this stub exists so contributors can see the heading
hierarchy and section ordering without opening Python.

1. Requirements (from strategy.json)
2. Current Best Angle (LLM summary)
3. Free AI Services To Use (table)
4. Easy Earning Ideas (numbered list with who-pays/deliverable/price/time/stack)
5. Next Actions (3-5 owner-only steps)
6. Monetization Patterns (from strategy.json)
7. Free AI Focus Areas (from strategy.json)
8. Reference Sources (title, URL, takeaway)
9. Underserved Niches (from strategy.json)
10. Strategy Playbook (from strategy.json)
11. Avoid (from strategy.json)
12. Ranked Leads From Online Search (score, value, reason, next step, codex prompt, outreach draft)

The module writes a real file every refresh_hours; if this stub is the only
thing present, code_techs is disabled in config or its refresh gate is not due.
