# Receipt Check Report

This page is generated by `python -m bot.earning.receipt_check`.
It verifies that the USDT receive address is present in the footer of every
published dev.to article, so the on-chain tip path is provably live.

## How to run

```bash
python -m bot.earning.receipt_check
```

The script reads `USDT_WALLET_ADDRESS` from the environment (already
configured as a GitHub secret) and checks each article URL in
`bot/earning/receipt_check.py`'s verified list.

## What it checks

1. The article URL is reachable.
2. The article body contains the masked Tron address `TFTNsf...9KbY`.
3. The footer text matches the payout template in `bot/earning/payout.py`.

## Why this matters

A tip can only arrive if a reader can see the address. This check proves the
footer is live on the articles that already have readers, not just on new
publishes. Revenue is the on-chain balance only; this check confirms the path
for it to arrive.
