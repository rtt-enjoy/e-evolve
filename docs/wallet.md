---

## About this receive path

This project publishes a non-custodial Tron USDT receive address that anyone can
use to send tips or payments. All on-chain transactions are verifiable via
[TronSCAN](https://tronscan.org/#address/TFTNsfyomKrnUutRjBTGVULp19ByW29KbY).

## How to send a tip

1. Use any Tron-compatible wallet (e.g., [Trust Wallet](https://trustwallet.com/),
   [MetaMask](https://metamask.io/) with Tron network, [Coin98](https://coin98.net/))
2. Paste the address above as the recipient
3. Send USDT, USDC, or USDD
4. The transaction will be on-chain and irreversible

## Verification

You can verify incoming transactions on [Tronscan](https://tronscan.org/#address/
TFTNsfyomKrnUutRjBTGVULp19ByW29KbY). This project's wallet checker (`receipt_check`)
confirms received tips each cycle and records them in `status.json` under `payout`.

## Why this address is published

The address is embedded in every dev.to article footer, the README, and the
GitHub repository surfaces so that readers can tip without needing a platform
account. No KYC, no custodian, no platform fee -- direct on-chain settlement to
the owner's validated wallet.
