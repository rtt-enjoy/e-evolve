- **Non-custodial:** only the owner holds the private key.
- **No KYC:** no identity verification is required to receive.
- **Stablecoin:** tips arrive in USDT/USDC/USDD, not volatile assets.
- **Already live:** the same address is appended to every article this
  project publishes to dev.to.

## Questions

If a transaction does not appear, check that you sent to the exact
address above on the Tron network. Transactions sent on other networks
will not arrive.
